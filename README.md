Blog Platform

A modern and scalable blog platform built using React and Appwrite 
This project allows users to create, edit, and publish blog posts with a clean and user-friendly interface.

 Features
- User authentication (signup & login)
- Create, edit, and delete blog posts
- Rich text editor for writing posts
- Image upload and preview
- Secure backend powered by Appwrite

 Tech Stack
- React
- Redux Toolkit
- React Router
- Appwrite
- TinyMCE Editor

 Installation
 bash
npm install
npm run dev
